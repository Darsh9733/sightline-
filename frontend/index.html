Keyboard Shortcuts Guide

  • Space or k: Play / Pause video & narration
  • r: Repeat last spoken description
  • d: Request more detail on current scene
  • q: Focus question input
  • j or ←: Jump backward 5 seconds
  • l or →: Jump forward 5 seconds
  • [ / ]: Decrease / increase speech speed
  • m: Mute / unmute original video
  • ?: Open this shortcuts guide
  • Escape: Close modal / cancel speech
